# Pairing-code font

JetBrains Mono Slashed NL Medium, release v2.304.
Source: https://github.com/sharpjs/JetBrainsMonoSlashed/releases/tag/v2.304

The unmodified no-ligatures medium font is embedded for consistent macOS and
Windows rendering. Its default zero is slashed. LICENSE.txt (SIL OFL 1.1) and
AUTHORS.txt are distributed alongside the font. Pairing-code validation still
excludes ambiguous characters; this is a visual change only.
