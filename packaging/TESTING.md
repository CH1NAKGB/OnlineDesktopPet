# Chick Link v0.3.3 测试说明

macOS：打开 DMG，将 Chick Link.app 拖入 Applications 后启动。
支持 Apple Silicon / Intel；当前是临时签名测试版，未做 Apple 公证。
Windows：完整解压 ZIP 后运行 pet-client.exe，系统托盘可打开聊天和退出。
当前 Windows 包未做代码签名。

## 本轮变化

- 配对和聊天页适配小窗口，统一圆角、边框和控件高度。
- 系统深浅色切换保持自定义样式，按钮显式 R10。
- 配对码居中，内置 JetBrains Mono Slashed NL Medium；占位提示使用纯字母数字。
- 自然呼吸、错开眨眼、抚摸缓入缓出，双端共享按时间计算的动作参数。
- 服务端提供初始化、启动、健康检查、日志和停止的统一入口。

## 建议测试

1. 右键小鸡打开配对页，检查缩放窗口、深浅色、按钮圆角和输入焦点。
2. 两端连接同一服务器，使用不同的个人令牌，任意一端输入另一端配对码。
3. 发送中英文与表情，检查消息历史、小鸡气泡和长昵称布局。
4. 测试拖拽、抚摸、60/120Hz 显示器与跨屏 DPI；实际帧率须真机测量。
5. 检查解除配对的双方确认，以及系统开机自启选项。

服务端部署及客户端环境变量见随包 QUICKSTART.md。当前公共包未内置
服务器地址和个人令牌；连接云端需按说明配置。默认本地地址为 127.0.0.1:8080。
服务端重启会丢失内存配对状态，需要重新配对；本地聊天历史保留。
